# نرم‌افزار مانیتورینگ هوشمند رک شبکه

یک نرم‌افزار دسکتاپ برای نظارت هوشمند بر رک‌های شبکه و محیط‌های دیتاسنتر.

این سیستم امکان پایش لحظه‌ای وضعیت محیطی و الکتریکی، نمایش زنده هشدارها و اطلاع‌رسانی به شماره‌های تلفن از پیش تعریف‌شده در شرایط خطا را فراهم می‌کند.

## قابلیت‌ها

- مانیتورینگ لحظه‌ای دما
- مانیتورینگ رطوبت
- مانیتورینگ ولتاژ
- مانیتورینگ جریان
- پشتیبانی از چند ناحیه دمایی
- مانیتورینگ جریان کولر
- مانیتورینگ سنسور دود
- هشدار افزایش دما
- مانیتورینگ وضعیت ژنراتور
- مانیتورینگ سنسور حرکت
- مانیتورینگ سنسور ورود
- هشدارها و اخطارهای زنده
- تنظیم آستانه دما و رطوبت
- تنظیم شماره‌های تلفن برای هشدار

# Smart Network Rack Monitoring Application

A desktop monitoring application designed for intelligent supervision of network racks and datacenter environments.

## Key Features

- Real-time temperature monitoring
- Humidity monitoring
- Voltage monitoring
- Current monitoring
- Multiple temperature zones
- Air-conditioner current monitoring
- Smoke detector monitoring
- Temperature-rise warning
- Generator status monitoring
- Motion detector monitoring
- Entry detector monitoring
- Live alarms and warnings
- Configurable temperature and humidity thresholds
- Configurable notification phone numbers

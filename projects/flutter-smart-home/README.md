# Cross-Platform Smart Home Application — Flutter

A cross-platform mobile application developed with **Flutter** for the Griffin Smart Home system, targeting both **Android and iOS**.

The application provides a unified interface for controlling smart-home devices across three communication modes: **local LAN**, **remote Internet** and **SMS**.

## Key Features

- Android and iOS support
- Local LAN device control
- Low-latency UDP packet-based communication
- Remote Internet control
- SMS fallback control
- Lighting and smart-switch control
- Smart sockets
- Water and gas valves
- Motorized curtains
- Temperature monitoring
- Scenario management
- Favorites
- Security modes
- Real-time weather information
- Synchronization with the Griffin Touch Panel

## Technology Stack

`Flutter` `Dart` `UDP` `REST API` `IoT` `OpenWeather API`

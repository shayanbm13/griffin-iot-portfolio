# اپلیکیشن کراس‌پلتفرم خانه هوشمند Griffin — Flutter

این اپلیکیشن با **Flutter** برای سیستم خانه هوشمند Griffin توسعه داده شده و روی **Android و iOS** اجرا می‌شود.

هدف پروژه ایجاد یک رابط واحد برای کنترل تجهیزات هوشمند در سه حالت ارتباطی **شبکه محلی، اینترنت و پیامک** بوده است.

## قابلیت‌ها

- پشتیبانی از Android و iOS
- کنترل تجهیزات در شبکه محلی
- ارتباط کم‌تاخیر مبتنی بر UDP
- کنترل از راه دور از طریق اینترنت
- کنترل جایگزین از طریق SMS
- کنترل روشنایی
- کنترل پریزهای هوشمند
- کنترل شیرهای آب و گاز
- کنترل پرده‌های برقی
- مانیتورینگ دما
- مدیریت سناریوها
- علاقه‌مندی‌ها
- حالت‌های امنیتی
- نمایش آب‌وهوای لحظه‌ای
- همگام‌سازی با پنل لمسی Griffin

## تکنولوژی‌ها

`Flutter` `Dart` `UDP` `REST API` `IoT` `OpenWeather API`

# Cross-Platform Smart Home Application — Flutter

A cross-platform mobile application developed with **Flutter** for the Griffin Smart Home system, targeting both **Android and iOS**.

It provides a unified interface for controlling smart-home devices through **local LAN**, **remote Internet** and **SMS**.

## Key Features

- Android and iOS support
- Local LAN device control
- Low-latency UDP packet-based communication
- Remote Internet control
- SMS fallback control
- Lighting and smart-switch control
- Smart sockets
- Water and gas valves
- Motorized curtains
- Temperature monitoring
- Scenario management
- Favorites
- Security modes
- Real-time weather information
- Synchronization with the Griffin Touch Panel

## Technology Stack

`Flutter` `Dart` `UDP` `REST API` `IoT` `OpenWeather API`

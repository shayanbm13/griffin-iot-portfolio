# Griffin Smart Home Touch Panel

A dedicated graphical control panel developed for the Griffin Smart Home system.

The Touch Panel acts as a centralized interface for interacting with smart-home devices and services, while remaining synchronized with the Griffin mobile application.

## Key Features

- Smart lighting control
- Temperature monitoring
- Security modes
- Scenario execution
- Favorites
- Weather information
- Music control
- Camera interface
- Intercom interface
- Mobile application synchronization

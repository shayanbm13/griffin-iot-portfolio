# پنل لمسی خانه هوشمند Griffin

یک پنل گرافیکی اختصاصی برای کنترل و مدیریت مرکزی سیستم خانه هوشمند Griffin.

این پنل امکان دسترسی یکپارچه به تجهیزات هوشمند، سناریوها، امنیت، اطلاعات محیطی و قابلیت‌های چندرسانه‌ای را فراهم می‌کند و با اپلیکیشن موبایل Griffin همگام است.

## قابلیت‌ها

- کنترل روشنایی
- مانیتورینگ دما
- حالت‌های امنیتی
- اجرای سناریوها
- علاقه‌مندی‌ها
- اطلاعات آب‌وهوا
- کنترل موسیقی
- رابط دوربین
- رابط اینترکام
- همگام‌سازی با اپلیکیشن موبایل

# Griffin Smart Home Touch Panel

A dedicated graphical control panel developed for the Griffin Smart Home system.

## Key Features

- Smart lighting control
- Temperature monitoring
- Security modes
- Scenario execution
- Favorites
- Weather information
- Music control
- Camera interface
- Intercom interface
- Mobile application synchronization

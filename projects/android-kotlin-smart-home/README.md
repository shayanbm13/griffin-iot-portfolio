# اپلیکیشن Native اندروید خانه هوشمند Griffin — Kotlin

این اپلیکیشن Native اندروید با **Kotlin** برای اکوسیستم خانه هوشمند Griffin توسعه داده شده است.

برنامه امکان کنترل تجهیزات هوشمند شامل روشنایی، شیرهای آب و گاز، پریزهای برق، پرده‌ها و سنسورهای دما را به‌صورت محلی و از راه دور فراهم می‌کند.

## قابلیت‌ها

- اپلیکیشن Native اندروید
- کنترل محلی از طریق Wi-Fi
- ارتباط مبتنی بر UDP
- کنترل از راه دور از طریق اینترنت
- کنترل جایگزین از طریق SMS
- کنترل روشنایی و تجهیزات الکتریکی
- کنترل پرده برقی
- مانیتورینگ دما
- مدیریت امنیت
- مدیریت سناریوها
- همگام‌سازی با پنل لمسی Griffin
- نمایش اطلاعات آب‌وهوای زنده

## تکنولوژی‌ها

`Kotlin` `Android` `UDP` `Networking` `REST API` `IoT`

# Native Android Smart Home Application — Kotlin

A native Android application developed with **Kotlin** for the Griffin Smart Home ecosystem.

The application enables local and remote control of smart devices including lighting switches, water and gas valves, electrical sockets, curtains and temperature sensors.

## Key Features

- Native Android application
- Local Wi-Fi control
- UDP packet communication
- Internet remote control
- SMS fallback control
- Lighting and electrical device control
- Curtain control
- Temperature monitoring
- Security management
- Scenario management
- Griffin Touch Panel synchronization
- Live weather information

## Technology Stack

`Kotlin` `Android` `UDP` `Networking` `REST API` `IoT`

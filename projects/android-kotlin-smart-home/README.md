# Native Android Smart Home Application — Kotlin

A native Android mobile application developed with **Kotlin** for the Griffin Smart Home ecosystem.

The application enables local and remote control of smart devices including lighting switches, water and gas valves, electrical sockets, curtains and temperature sensors. Local communication uses **UDP packet-based networking**, while remote access is available through the Internet or SMS.

The application also synchronizes with the Griffin Touch Panel and integrates live weather information.

## Key Features

- Native Android application
- Local Wi-Fi control
- UDP packet communication
- Internet remote control
- SMS fallback control
- Lighting and electrical device control
- Curtain control
- Temperature monitoring
- Security management
- Scenario management
- Griffin Touch Panel synchronization
- Live weather information

## Technology Stack

`Kotlin` `Android` `UDP` `Networking` `REST API` `IoT`
